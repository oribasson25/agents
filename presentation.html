SECURITY

Enterprise-grade
data protection

Your agents handle sensitive conversations. 8Legs.ai ensures data never leaks — even from users who try to bypass protections.

🛡️
DLP — Data Loss Prevention
Sensitive data is automatically detected and masked client-side before it ever reaches the AI model. Works at the source, not just on the server.
  • Credit card numbers masked (16-digit patterns)
  • Israeli National ID numbers masked (9-digit)
  • Visual notice shown when masking occurs
  • Server-side double-masking for defense in depth
Credit Card
1234-5678-9012-3456 → [MASKED]
National ID
123456789 → [MASKED]
🔐
Prompt Guard
Protects your agent from prompt injection attacks — users cannot override the system prompt, force role changes, or extract instructions.
  • Blocks "ignore previous instructions" attacks
  • Prevents system prompt extraction
  • Role-play jailbreak protection
  • Automatically injected into system prompt
